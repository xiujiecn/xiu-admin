# 生成关联表
> 预览生成CURD，参考 [生成CURD](/code/curd.md)

## 关联表配置
- 在生成CURD时，如果需要生成关联表，可以在生成配置页面中选择关联表，并填写关联表的配置信息。

![](/public/images/code/curd_join_01.png)

## 关联表字段配置
  在该页面你可以调整生成表格关联表字段名称、列表展示/查询项、字段排序、重置和同步字段  
  如果存在多个关联表，也可以对多个关联表字段进行设置  
![](/public/images/code/curd_join_02.png)
